# Tiefenjournal
Ein Journal, das Fragen stellt statt Antworten gibt. Sokratischer Dialog aus den eigenen Einträgen, 136 Gefühlswörter für mehr emotionale Granularität, Ambivalenz als Venn-Diagramm. Whisper-Spracherkennung offline im Browser, alle Daten bleiben auf dem Gerät.
